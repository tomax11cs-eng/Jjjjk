## What this project is

A single-page CZK → EUR currency converter, set up as an installable PWA so iPhone users can "Add to Home Screen" and use it like a native app. The whole app lives in `index.html` — markup, styles, and logic are inlined; there is no build step, no package manager, and no backend.

Files that ship alongside `index.html`:

- `manifest.json` — PWA metadata (name, theme color, icons).
- `sw.js` — service worker. Pre-caches the app shell; for the Frankfurter API uses a network-first-with-cache-fallback strategy so the last good rate is available offline.
- `icon-180.png` — Apple touch icon (home screen on iOS).
- `icon-192.png`, `icon-512.png` — PWA manifest icons.
- `README.md` — user-facing description, in Slovak.
- `.github/workflows/pages.yml` — CI that deploys the repo root to GitHub Pages.

Icons are generated by `/tmp/make_icon.py` (kept out of the repo; regenerate if the visual identity changes — gradient and labels are defined there).

## Running it

Open `index.html` in a browser. There is no dev server, no `npm`, no tests. Any static host (GitHub Pages, Netlify, etc.) works as deployment. The service worker only registers under HTTPS or `localhost`, so loading the file via `file://` will skip the offline-cache path but the page still functions.

## Deployment

`.github/workflows/pages.yml` deploys the entire repo root to GitHub Pages on every push to `main` (or via manual `workflow_dispatch`). There is no build step — the workflow uploads the directory as-is and publishes it. Pushing to `main` is therefore a live deploy; feature branches do not deploy.

## Architecture notes

- **Exchange rate source:** the page fetches `https://api.frankfurter.app/latest?from=CZK&to=EUR` on load. Frankfurter mirrors ECB reference rates and updates on business days (~16:00 CET). It is free, keyless, and CORS-enabled — do not swap it for an API that requires a key without first asking the user.
- **Two-way binding:** both input fields (`#czk`, `#eur`) edit the same conceptual amount. A `direction` flag tracks which side the user is currently typing in, so `recalculate()` knows whether to multiply by `rate` or divide.
- **Offline behavior:** once the rate is fetched, conversions work without network. There is no caching of the rate across reloads — a fresh fetch happens every page load, which is also how the "daily updated" guarantee is satisfied.
- **Swap button (`#swapBtn`):** the `⇅` button swaps the two field values and flips `direction`, then recalculates — it does not re-fetch the rate.
- **Service worker cache version:** `sw.js` keys its cache as `czk-eur-v1` and deletes any other cache on `activate`. When you change a shell asset (`index.html`, icons, `manifest.json`), bump this version string so clients pick up the new files instead of serving the stale cached shell.

## Conventions

- UI strings are in Slovak. Keep them in Slovak unless the user asks for another language.
- Keep the app a single self-contained file unless complexity genuinely demands splitting it. Do not introduce a framework, bundler, or package.json without being asked.
